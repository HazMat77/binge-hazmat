# Binge Hazmat

Binge Hazmat TV - all in one. Android TV / Fire TV / phone app.

## Install

Use Downloader on your Fire TV / Android TV and enter this code:

**5719852**  (or open aftv.news/5719852)

Or download one of these files directly:

- `BingeHazmat-arm.apk` - works on every device (32-bit and 64-bit)
- `BingeHazmat-arm32.apk` - smaller file for 32-bit boxes
- `BingeHazmat-arm64.apk` - smaller file for 64-bit boxes

The app checks `version.json` in this repo and offers updates from inside the app.
